- **Task02:** Tokens, Keywords, Identifiers & `constexpr` Constants
- **Task03:** Data Types, Sizes, Compatibility & Overflow Prevention
- **Task04:** Controlling Implicit Conversions & Cast Forensics
- **Task05:** Expressions, Precedence & Integer Truncation Rules
- **Task06:** Control Structures & Complete the Code Implementation
- **Task07:** Procedural vs Object-Oriented Paradigm Comparison
- **Task08:** Safe I/O, Stream Error Recovery & Formatting

- **Task10:** Execution Analysis: Floating-Point Drift vs Exact Integers
- **Task11:** Engineering Recommendation & Defended Final Architecture
- **Task12:** Day-4 Design Challenge: Airport Zone & Weekend Pass Extensions

### [Assignment 2: CO2 - Functions and Classes in C++](Assignment/Assignment-2/README.md)
*Focus: Call by value/ref/pointer, return by reference, default arguments, overloading, encapsulation, static members, friend functions.*

- **Task06 (Q6):** Friend Functions, Inline Member Functions & Symmetrical Time Ops
- **Task07 (Q7):** Day-4 Design Challenge: Diagnosing & Redesigning Seat Allocation Engine

### [Assignment 3: CO3 - Constructors, Destructors and Operator Overloading](Assignment/Assignment-3/README.md)

### [Assignment 4: CO4 - Designing Reusable Class Hierarchies & Pointers](Assignment/Assignment-4/README.md)
